# GPT 이미지 스튜디오 — 카드뉴스 5장 기능 추가

기존 단일 이미지 생성 화면과 새 카드뉴스 일괄 생성 화면이 탭으로 나뉘어 있습니다.

## 추가된 기능
- 서로 다른 프롬프트를 입력하는 1~5장 카드뉴스 생성
- 공통 디자인 지침으로 시리즈 스타일 통일 요청
- 각 카드 개별 PNG 저장, 개별 재생성, 전체 ZIP 저장
- 기존 1~4장 동일 프롬프트 생성 화면 유지
- 기존 세션당 8장 생성 상한을 두 모드에서 공동 사용

## 기존 사이트에 적용하기
1. ZIP 압축을 풀고 `app.py`, `requirements.txt`, `README.md`, `.gitignore` 파일을 확인합니다.
2. GitHub의 기존 이미지 스튜디오 저장소에 파일을 업로드합니다. 기존 `app.py`는 **교체(덮어쓰기)** 합니다. **ZIP 파일 자체를 올리는 것이 아닙니다.**
3. GitHub에서 `Commit changes`를 누릅니다. 연결된 Streamlit Cloud 앱은 일반적으로 변경 사항을 자동으로 다시 배포합니다.
4. 기존 Streamlit 앱 URL을 열고 `🗂️ 카드뉴스 5장 일괄 생성` 탭에서 이용합니다.

## API 및 사용 주의
- OpenAI API 키는 **각 이용자가 사이드바에 직접 입력**합니다. `.env`, `secrets.toml`, 키가 담긴 파일을 GitHub 공개 저장소에 업로드하지 마세요.
- 모델 목록은 원본 앱의 값을 그대로 유지했습니다. 사용 권한이 없거나 지원되지 않는 모델명을 선택하면 API 오류가 발생할 수 있습니다. 해당 경우 사용 가능한 모델을 선택해 주세요.
- 5장 일괄 생성은 서로 다른 API 요청 5번에 해당하며, 생성 장수만큼 요금이 발생할 수 있습니다.
- 시리즈 디자인 일치는 프롬프트 지침으로 유도하는 방식이라 완전히 동일한 서체·캐릭터를 보장하지 않습니다. 한국어 텍스트의 오타도 결과에서 확인하세요.
- 이 앱의 8장 제한은 현재 Streamlit 세션 단위이며 서버 전체 비용 제한이 아닙니다. 앱 새로고침/세션 초기화 후 한도가 초기화될 수 있습니다.
- API 키는 코드/ZIP에 포함되지 않습니다. 공개 사이트에서는 서비스 운영자 및 배포 플랫폼의 보안 정책을 확인하세요.
